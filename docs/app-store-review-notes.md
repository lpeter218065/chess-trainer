# App Store 审核备注

本 App 是离线国际象棋训练器（课程、开局练习、自由探索、引擎评估）。讲解是可选增强：不填写 API Key 时，走子、评估、课程目标判定全部可用。

## 讲解功能（可选）测试方式

设置页填写 OpenAI 兼容接口：

- Base URL：例如 `https://api.openai.com/v1`（填到 `/v1` 为止）
- API Key：请使用审核方提供的测试 Key。本仓库与本备注不含真实密钥，请勿把 Key 打进构建产物。
- 模型：例如 `gpt-4o-mini`

填写后点「测试连接」。不配 Key 时请直接走课程或自由探索，确认训练功能完整。

## 隐私

App Store Connect 隐私问卷：不收集数据，无追踪，无账号。

- API Key 只存本机 Keychain（Web 为本地存储）
- 讲解请求发往用户自己填写的服务地址
- 本项目没有任何自有服务器
